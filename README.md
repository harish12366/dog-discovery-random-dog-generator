# 🐶 Dog Discovery

A responsive random dog image generator built using **HTML, CSS, and JavaScript**. The project uses the **Dog CEO API** to fetch and display a different dog image whenever the user clicks the button.

## 🚀 Features

- Fetches a random dog image from an API
- Displays a new dog image on every button click
- Uses JavaScript `async/await` for API requests
- Includes `try...catch` error handling
- Displays loading and error messages
- Responsive design for different screen sizes
- Simple and clean user interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Fetch API
- Dog CEO API
